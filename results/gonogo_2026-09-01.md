# S3 separability gate — GO / NO-GO

**Date:** 2026-09-01 (D3) · **Days to submission deadline:** 55
**Question:** does diffuse-boundary contrast (S3) separate smoke's soft edge from a fog bank's?

> **This document was written BEFORE the script was run.** Sections 1–5 are fixed commitments.
> Section 6 is filled in from the output, whatever it says. That order is what makes this a gate
> rather than a formality — see `specs/complexity.md` §6.5.

---

## 1. What is being decided

Whether PlumeRank's anchored plume-growth primitive has a viable third statistic. S1 (base anchoring)
and S2 (vertical growth anisotropy) are both satisfied by a coastal marine layer: fog anchors to
terrain and grows vertically. **S3 is the only statistic that discriminates.** If it cannot, the
primitive fails against its real adversary and the project premise is gone.

This gate does **not** test stabilisation, MOG2, tracking, hazard fusion or the budget solver. A rate
per camera-night is not computable from static crops; that question is the **D11 budget checkpoint**
(2026-09-09), not this one.

## 2. The decision rule — fixed in advance

95% bootstrap CI on AUC (2,000 draws, seed 20260901, resampling each class independently):

| Verdict | Rule | Consequence |
|---|---|---|
| **NO-GO** | CI **upper** bound < 0.70 | **Abandon PlumeRank. Switch to FlashBudget, with 55 days left.** |
| **GO** | CI **lower** bound ≥ 0.70 | Proceed. D11 becomes confirmation, not rescue. |
| **CONDITIONAL GO** | CI **straddles** 0.70 | Proceed, **and D11 becomes a hard abort gate** whose criteria are §4 below. |

**The NO-GO sentence, written before the number exists:**

> If the 95% CI upper bound on AUC is below 0.70, S3 cannot separate smoke from fog, the anchored
> plume-growth primitive has no discriminating statistic, and PlumeRank is abandoned on 2026-09-01 in
> favour of FlashBudget. This is a good outcome today and a catastrophic one on 10 October. It will
> not be renegotiated after seeing the number, and no variant search will be used to overturn it —
> the variants are enumerated in advance (§3) and their selection cost is disclosed (§5).

The decision is taken **on the interval, not the point estimate.** At n=60/60 the standard error on
AUC is ≈0.045, so the 95% CI half-width is ≈0.087. A point-estimate rule at these thresholds would
return a confident verdict on noise roughly 27% of the time when the true AUC is 0.70.

## 3. The variants, enumerated before the run

Each is a flag on the same script, not a new code path. Run only if v0's CI straddles the cutline.

| | Variant | Rationale |
|---|---|---|
| v0 | raw-frame ratio | the specified statistic |
| v1 | multi-scale Laplacian, max over three σ | plume boundaries live at a different scale than fog banks |
| v2b | halved boundary band width | the band width is a guess |
| v3 | log of the ratio | ratios of energies are heavy-tailed |
| v4 | normalised by ROI mean intensity | S3 should not be measuring absolute brightness |
| **v5** | **S3 on the temporal difference frame** | **the most likely rescue** — a fog bank's boundary is near-stationary between frames while a plume's advances, so differencing suppresses fog's edge and preserves smoke's |

## 4. The D11 abort criteria — written now, measured 2026-09-09

At the threshold `rank.py` calibrates to 2.0 alerts/camera-night over the whole CONFUSE arm, measure
what the **fog windows alone** contribute:

- **< 0.5 alerts/camera-night from fog** → clear. The original GO condition is met on real evidence.
- **> 1.5 from fog** → fog eats the budget every morning. **The primitive has failed against the real
  adversary; the descope decision is taken on D11 with 47 days left.**
- **between** → publish the number, proceed, and it becomes a named limitation in `REPORT.md` and a
  row on `/results`.

## 5. The instrument, and its known limitations

- `spike/s3_separation.py` (~200 lines), `spike/urls.txt` (120 URLs), `spike/boxes.json`
  (120 hand-drawn boxes, one per image). Committed, so the gate is reproducible by someone else.
  `spike/frames/` is gitignored — HPWREN imagery, regenerable from `urls.txt`.
- **Smoke: 60 frames from 20 FIgLib sequences** (2024–2026), at t+15/+25/+35 min after the recorded
  visible-plume appearance. The 20 sequences were **screened for an actually-visible plume** — about
  half of FIgLib's sequences name a fire that is not in that camera's frame, and an unscreened sample
  would have measured haze. Screening was a localized-change score between t−30 and t+30 min,
  followed by visual confirmation of every retained sequence.
- **Fog: 60 frames from ~20 dawn mornings** at 06:00–08:59 Pacific, drawn from the HPWREN
  medium-term camera archive across June–August 2026, on the same camera platforms
  (`hp-*`, `wilson-*`, `tdlln-*`). Selected by a within-camera fog score, then visually confirmed as
  genuine marine layer. One total-whiteout morning was excluded: with the camera inside the cloud
  there is no boundary to box, and this statistic measures boundaries.
- **LIMITATION, stated up front:** the smoke frames are FIgLib (2024–2026) and the fog frames are the
  medium-term archive (2026). Same camera platforms, **different dates and partly different years.**
  The spec assumed dawn fog could be drawn from FIgLib itself; it cannot — FIgLib publishes only
  ±40 min around each ignition, and ignitions cluster between 11:00 and 17:00 Pacific, so dawn is
  almost absent from it. This is a real difference between the two classes and it is disclosed here
  rather than discovered later.
- **LIMITATION:** boxes are hand-drawn by one person who knows which class each image belongs to.
  The box placement is therefore not blind. Mitigation: the band width `b` is fixed a priori and no
  constant is fitted anywhere in the statistic.

## 1. The headline: the project is off its abort branch, and it took a fix nobody had scheduled

D11's binding quantity — fog's own alert rate — was **1.5385 on 2026-09-05, above the 1.5 abort
cutline**, measured on an instrument the spec says was not finished: `constants.py` carried
a-priori fusion weights while the original plan (D11) specifies "a weighted logistic, weights fit on
DEV". The weights were never fit.

Fitting them moved the number to **1.1538 — inside the proceed band** (`class_split_2026-09-06.json`).

The ruling that decided which quantity binds (`ruling_d11_contribute.md`) was written and
committed **before** the fitted number existed, and it chose the *unfavourable* reading of an
ambiguous criterion on three independent grounds. The verdict is also robust: it came out 1.0769
under one escalation configuration and 1.1538 under another, both in the same band.

**VERDICT: PROCEED, published as a named limitation.**

## 3. Three findings that change what the project believes about itself

**(a) The adversary is cloud, not fog.** At the fitted operating point:

| class | own rate | | class | own rate |
|---|---:|---|---|---:|
| **low_cloud** | **4.2500** | | exposure_hunting | 1.4000 |
| **cloud_shadow** | **3.8571** | | lens_artefact | 0.0000 |
| fog_marine | 1.1538 | | dust | 0.0000 |

the project record names fog as the biggest risk and the whole design follows from it. Fog is
**fourth**, below `exposure_hunting`, at half its allowance — while two cloud classes run at
double theirs. The predicted risk is not the realised one.

**(b) S3 was under-weighted, not over-weighted.** `gonogo §7.4` proposed that unfitted weights
over-weighted S3, letting hard-edged regions through. The fit says the reverse: S3 moves 2.6 →
**4.0931** while S1 falls 1.9 → 0.6164 and S2 1.4 → 0.3856. That explanation for cloud shadow is
**falsified**.

**(c) Half the fog class is not fog.** Of 54 of the 60 frames inspected, roughly 27 show a clear
or lightly-clouded dawn with no marine layer; about 8 show one clearly. This explains `§7.5`'s
unexplained note that the original fog predicate admitted **0 of 60** — the a-priori cutlines
were rejecting non-fog correctly. The predicate was then re-derived from that same set, so the
contamination has propagated into the CONFUSE arm's `fog_marine` class. **The comfortable
1.1538 is a rate on a class whose membership is in doubt**, and that caveat travels with it.
